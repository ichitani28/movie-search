# 映画まとめ動画検索

登録9チャンネルの映画まとめ・シーン動画を、スマホのブラウザからタイトルで探せる静的サイトです。ビルド手順は不要です。

## ファイル

- `index.html` — 検索画面（バニラJSのみ。外部ライブラリやCDNは使いません）
- `video.html` — 動画の詳細ページ（サムネイル・広告枠・YouTubeへの導線。同じチャンネルの人気動画も表示）
- `data.json` — 動画データ（id・タイトル・チャンネル・ショート識別・視聴回数）
- `.nojekyll` — GitHub Pages が Jekyll でファイルを無視しないようにするための空ファイル

## 公開（GitHub Pages）

1. このフォルダを GitHub リポジトリに置く
2. リポジトリの Settings → Pages で、ソースをデフォルトブランチのルート（またはこのフォルダをルートにしたブランチ）にする
3. 公開後、`https://<user>.github.io/<repo>/` をスマホのホーム画面に追加すると使いやすくなります

ローカル確認:

```bash
python3 -m http.server 8080
# http://127.0.0.1:8080/ を開く
```

## データについて

収録は 2026年11月13日 12:45（日本時間）時点の YouTube 公開アップロード一覧です。合計 17,308 本（ショート 95 本）。9チャンネル目として「映画ドラマ二アック」を追加し、19本（すべて通常動画。ショートなし）を収録しています。このうち公式の公開アップロード一覧は15本で、残る4本はメンバー限定などで視聴回数を取得できませんでした。映画カルチュア FilmIsNow Japan は公開一覧の 11,477 本で、以前確認したチャンネル総数（11,540 本）より 63 本少ないです。ほかのチャンネルは総数と一致しています。投稿日は一覧に含まれていませんでした。
