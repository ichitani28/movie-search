# 映画まとめ動画検索

登録8チャンネルの映画まとめ・シーン動画を、スマホのブラウザからタイトルで探せる静的サイトです。ビルド手順は不要です。

## ファイル

- `index.html` — 検索画面（バニラJSのみ。外部ライブラリやCDNは使いません）
- `video.html` — 動画の詳細ページ（サムネイル・広告枠・YouTubeへの導線。同じチャンネルの人気動画も表示）
- `data.json` — 動画データ（id・タイトル・チャンネル・ショート識別・視聴回数）
- `.nojekyll` — GitHub Pages が Jekyll でファイルを無視しないようにするための空ファイル

## 公開（GitHub Pages）

1. このフォルダを GitHub リポジトリに置く
2. リポジトリの Settings → Pages で、ソースをデフォルトブランチのルート（またはこのフォルダをルートにしたブランチ）にする
3. 公開後、`https://<user>.github.io/<repo>/` をスマホのホーム画面に追加すると使いやすくなります

ローカル確認:

```bash
python3 -m http.server 8080
# http://127.0.0.1:8080/ を開く
```

## データについて
